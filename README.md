# SiegeBot — 攻城戦の兵士ボット

同じチームのプレイヤーのチャットを理解して動く、疑似プレイヤー（NPC の兵士）を出す Paper プラグインです。
味方がいないときは、設定に書いた初期指示で動きます。門が開くと、同じ方針のまま前線を移します。

- 対応: Paper 26.1.2 / Java 25
- 必要なプラグイン: [Citizens](https://ci.citizensnpcs.co/job/Citizens2/)（2.0.44 build 4269 で確認）
- 任意のプラグイン: [ItemJoin](https://modrinth.com/plugin/itemjoin)（6.1.8 で確認。指揮棒を配るのに使う）
- 指示の理解: まずキーワードで判定し、読み取れない発言だけ Claude API（Anthropic の API キー）に回します。`chat.parser` で切り替えられます（`auto` / `keyword` / `llm`）。API キーがなくてもキーワードで動きます

## 導入

1. [Releases](../../releases) から `SiegeBot-0.1.0.jar` を取ってくるか、自分でビルドします（下の「ビルド」）。
2. サーバーの `plugins` フォルダに、Citizens の jar と `SiegeBot-0.1.0.jar` を入れて起動します。
   指揮棒を使うなら、ItemJoin の jar も入れ、[`itemjoin/items.yml`](itemjoin/items.yml) を `plugins/ItemJoin/items.yml` に置きます。
3. `plugins/SiegeBot/config.yml` を開き、次の 2 つを書きます。
   - `teams.attack` / `teams.defend`: 攻め・守りのスコアボードのチーム名（`/team` で作ったチームの名前）
   - `llm.api-key`: Anthropic の API キー（任意。なくてもキーワード判定で動きます。使うなら利用上限を低くした専用のキーを勧めます）
4. `/siegebot reload` で読み直します。

## 最初の設定（ゲーム内で行う）

コマンドは OP 権限（`siegebot.admin`）が必要です。`/sb` と短く書けます。

1. **場所に名前を付ける** — その場所に立って実行します。
   ```
   /sb place set 外門前
   /sb place set 中庭
   /sb place alias 中庭 なかにわ
   ```
   別名を付けておくと、チャットでその呼び方をしても通じます。
2. **門を登録する** — 攻め手が通る順に登録します。門のブロックの対角の 2 か所を見て（または立って）実行します。
   ```
   /sb gate pos1 外門
   /sb gate pos2 外門
   ```
   コマンドブロックで門のブロックが消えると、その門は「開いた」と判定されます。
3. **段階ごとの前線を決める** — 段階 0 は門が 1 つも開いていない状態、段階 1 は 1 つ目の門が開いた状態です。
   ```
   /sb front 0 attack 外門前
   /sb front 0 defend 外門の内側
   /sb front 1 attack 中庭
   /sb front 1 defend 中庭
   ```
   未設定の段階は、手前の段階の場所を使います。
4. **リスポーン地点を決める**
   ```
   /sb spawnpoint attack 攻め陣地
   /sb spawnpoint defend 本丸
   ```
5. **ボットを出す**
   ```
   /sb spawn Bot1 attack
   /sb spawn Guard1 defend
   ```
   出したボットは保存され、サーバーの再起動後も出てきます。消すときは `/sb remove Bot1`。

## 専用のボット（プレイヤー 1 人に 1 体）

既定では、攻め・守りのチームに入っているプレイヤー 1 人につき 1 体、その人専用のボット（「名前の兵」）が出ます。

- 参加すると数秒でリスポーン地点に出て、抜けると消えます。チームを移ると、新しい陣営で出し直します。
- 指示（指揮メニュー・`/sbc`・チャット）は、自分のボットにだけ効きます。他の人のボットには指示できません。
- `/sb spawn` で出したボットは持ち主がいないので、誰の指示も受けず、`default-orders` の初期指示で動きます。
- 管理者の `/sb order` だけは、陣営のボット全員に効きます（試験用）。
- `config.yml` の `personal-bots.enabled: false` で、以前の「チームの誰でも全員に指示できる」形に戻せます。

## アイテムで指示する（ItemJoin）

[ItemJoin](https://modrinth.com/plugin/itemjoin)（6.1.8 で確認）を入れると、参加時とリスポーン時に「指揮棒」が配られます（ホットバーの 9 番目）。
`itemjoin/items.yml` を `plugins/ItemJoin/items.yml` に置くか、中の `siegebot-baton` を既存の items.yml に足してください。

指揮棒を右クリックすると指揮メニューが開きます。

| 段 | ボタン | 押したとき |
|---|---|---|
| 1 段目 | 自分のボットの頭（専用のボットのとき） | 今の方針と生死を表示する |
| 1 段目 | 全員に指示 / 各ボットの頭（`personal-bots.enabled: false` のとき） | 指示する相手を選ぶ。画面は開いたまま |
| 2 段目 | ついてこい・前線へ・ここを守れ・下がれ | 選んだ相手に指示して画面を閉じる |
| 3 段目 | 登録した場所（最大 9 か所） | その場所を守らせて画面を閉じる |
| 4 段目 | 構え: 積極的 / 持ち場優先・閉じる | 構えだけを変える（動きはそのまま）。画面は開いたまま |

選択中の相手と今の構えのボタンは光ります。メニューは `/sbc` で開くので、ItemJoin なしでも使えます。
`/sbc` は OP でなくても使え（権限 `siegebot.command`）、自分のチームのボットにだけ効きます。
`/sbc follow` `/sbc hold 中庭` のように直接打つこともできます。

## チャットで指示する

同じチームのプレイヤーが、通常のチャットか `/tm`（チームチャット）で普通に話しかけます。

- 「全員、前線に出て」
- 「Bot1 は中庭を守って。残りは俺についてきて」
- 「Guard1、無理に追わないで持ち場にいて」

ボットは短く復唱し、方針を切り替えます。方針は次の 3 種類の組み合わせです。

| 方針 | 動き |
|---|---|
| 前線 | 今の侵攻度の前線へ行って戦う。門が開くと自動で次の前線へ移る |
| 場所を守る | 名前を付けた場所にとどまって戦う |
| 追従 | 指定したプレイヤーについていき、近くの敵と戦う |

それぞれに「積極的（広い範囲の敵を追う）」「持ち場優先（近づいた敵とだけ戦う）」の構えがあります。

味方のプレイヤーがチームから 1 人もいなくなると、`config.yml` の `default-orders` の指示に戻ります。

## コマンド一覧

| コマンド | 内容 |
|---|---|
| `/sb spawn <名前> <attack\|defend>` | ボットを出す |
| `/sb remove <名前>` | ボットを消す |
| `/sb list` | ボットと現在の方針の一覧 |
| `/sb place set\|remove\|alias\|list` | 場所の登録・削除・別名・一覧 |
| `/sb gate pos1\|pos2\|remove\|list` | 門の登録・削除・一覧（開閉の状態つき） |
| `/sb front <段階> <attack\|defend> <場所>` / `front list` | 段階ごとの前線 |
| `/sb spawnpoint <attack\|defend> <場所>` | リスポーン地点 |
| `/sb stage [数字\|auto]` | 侵攻度の表示・手動での固定・自動に戻す |
| `/sb order <attack\|defend> <文章>` | チャットの代わりに指示を送る（コンソールからの試験用） |
| `/sb set <ボット\|*> <front \| hold <場所> \| follow <プレイヤー>> [push\|guard]` | LLM を通さずに方針を直接設定する（API キーがないときの代わり） |
| `/sb debug` | 各ボットの位置・体力・狙っている相手・移動中かどうかを表示する |
| `/sb tp <ボット> <場所 \| x y z>` | ボットを瞬間移動させる（詰まったときの救出・試験用） |
| `/sb protect <ボット> <on\|off>` | ボットを無敵にする・戻す（試験用） |
| `/sb reload` | 設定の読み直し |

## 知っておくこと

- **歩ける距離**: 前線から次の前線までが `combat.path-range`（既定 96 ブロック）より遠いと、経路が見つからず歩けません。遠い場合は値を上げるか、途中の段階に前線を置いてください。
- **詰まったとき**: 瞬間移動はさせていません。その場で経路を取り直します。
- **門の判定**: 範囲の 9 割以上が空気になると「開いた」とみなします（`gates.open-air-ratio`）。門の開け方が違う場合は `/sb stage <数字>` を門を開けるコマンドと一緒に実行してください。
- **キーワード判定で通じる言い方**: ボット名（`A1`）や番号（「1番」「ボット2」）、「全員」「残り」「俺」、場所名とその別名、
  動きの言葉（前線・攻めろ・突撃／守れ・待機・集合・固めろ／ついてきて・護衛／下がれ・戻れ）、
  構えの言葉（突っ込め・ガンガン／深追いするな・無理するな）を組み合わせて読み取ります。
  「A1は中庭、残りは俺についてきて」のように「、」で区切れば、ボットごとに別の指示を出せます。
  疑問文（「前線どうなってる？」）は、「〜してくれる？」の形でなければ指示とみなしません。
  ボットは指示を受けると「了解。場所「中庭」・持ち場優先」のように復唱するので、取り違えはその場で気づけます。
- **LLM を使うときの料金**: `chat.parser: auto` では、キーワードで読み取れなかった発言だけ LLM を呼びます（ボットが何体いても 1 回）。
  雑談でも呼ばれるので、気になる場合は `chat.prefix` に `!` などを設定するか、`chat.parser: keyword` にしてください。
- **狙いの選び直し**: 一度狙った敵でも、2 秒ごと（`combat.retarget-seconds`）に周りを見直し、今の相手より 2 ブロック以上近い敵がいれば狙いを替えます。
  今の相手が倒れた・見えなくなった・範囲を出たときは、すぐに選び直します。
- **敵に気づく条件**: 16 ブロック以内で、見えている敵だけを狙います（5 ブロック以内なら見えていなくても気づきます）。壁の向こうの敵とは戦いません。
- **体力**: ボットの体力は自然には回復しません。倒されると 10 秒後にリスポーン地点で全快で復活します。
- **Citizens の初回起動**: Citizens は最初の起動のときに、必要なライブラリを外部（Maven Central）からダウンロードします。サーバーから外へ通信できる必要があります。
- **同士討ち**: ボットと同じ陣営のプレイヤー・ボットの間の攻撃は無効になります。
- **まだできないこと**: バフボタンの設置、弓などの遠距離攻撃、ブロックの設置・破壊。

## ビルド

Java 25 と Maven 3.9 以降が必要です。

```
mvn package
```

`target/SiegeBot-0.1.0.jar` ができます（テスト 74 件も走ります）。
Windows では `build.cmd package` でも同じです（`tools/apache-maven-*` に Maven を置けばそれを、なければ PATH の `mvn` を使います）。

## リポジトリの中身

| パス | 内容 |
|---|---|
| `src/main/java/siegebot` | プラグイン本体 |
| `src/test/java/siegebot` | 単体テスト（JUnit 5） |
