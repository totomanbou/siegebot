# SiegeBot — 攻城戦の兵士ボット

攻城戦で、プレイヤー 1 人に 1 体ずつ、その人の指示で動く兵士ボット（プレイヤーの姿の NPC）を付ける Paper プラグインです。
指揮棒を右クリックして開くメニューから、「ついてこい」か「視点の先を守れ」を選び、構え（積極的・持ち場優先）を決めます。

- 対応: Paper 26.1.2 / Java 25
- 必要なプラグイン: [Citizens](https://ci.citizensnpcs.co/job/Citizens2/)（2.0.44 build 4269 で確認）
- 任意のプラグイン: [ItemJoin](https://modrinth.com/plugin/itemjoin)（6.1.8 で確認。指揮棒を配るのに使う）、
  [CombatLog](https://modrinth.com/plugin/combatlogplugin)（1.2.1 で確認。入っていれば、戦闘中は「呼び寄せる」を使えない）
- 外部との通信: SiegeBot 自体はしません

## 導入

1. [Releases](../../releases) から `SiegeBot-0.19.0.jar` を取ってくるか、自分でビルドします（下の「ビルド」）。
2. サーバーの `plugins` フォルダに、Citizens の jar と `SiegeBot-0.19.0.jar` を入れて起動します。
   指揮棒を使うなら、ItemJoin の jar も入れ、[`itemjoin/items.yml`](itemjoin/items.yml) を `plugins/ItemJoin/items.yml` に置きます。
3. `plugins/SiegeBot/config.yml` の `teams.attack` / `teams.defend` を、攻め・守りのスコアボードのチーム名（`/team` で作ったチームの名前）に合わせ、`/sb reload` で読み直します。
   既定は `Attack` と `Defence` です。SiegeBot は大文字・小文字を区別せずに比べますが、コマンドのセレクタ（`@a[team=Attack]`）は区別するので、チーム名はそろえておくのが安全です。
4. 必要ならリスポーン地点を決めます（OP が必要）。その場所に立って実行します。
   ```
   /sb spawnpoint attack
   /sb spawnpoint defend
   ```
   決めない場合、ボットは持ち主の横に出ます。
5. ボットを出すコマンドブロックを置きます（下の「ボットの参戦」）。

## 専用のボット

攻め・守りのチームに入っているプレイヤーに、その人専用のボット（「名前の兵」「名前2の兵」…）を出せます。
1 人が複数体持てます（上限は `personal-bots.max-per-player`、1〜30 の範囲で既定 5 体）。何体・どの兵種を出すかはコマンドブロックで決めます。
名前は 16 文字以内に収めます（2 桁の番号になっても同じ）。
大人数（10 体を超えるような編成）は、ボットの経路探索・戦闘の処理が人数に比例して増えるので、サーバーの負荷に気を付けて上限を決めてください。
兵種は剣兵（「名前の兵」）・槍兵（「名前の槍兵」）・弓兵（「名前の弓兵」）の 3 つです（下の「兵種」）。

- 参加しただけでは出ません。コマンドブロックの `/sb revive` で出します。
- 出た直後は、持ち主についていきます（持ち場優先）。
- 指示（指揮メニュー・`/sbc`）は、自分のボットと、指揮権を譲られて預かっているボット（下の「指揮権の譲渡」）にだけ効きます。それ以外の人のボットには指示できません。
- ボットの発言（「了解。…」「到着した」「参戦した」など）と死亡メッセージ（「○○の兵 was slain by …」）は、持ち主にだけ見えます。
  死亡メッセージはサーバーのログにも残ります。
- **持ち主が死ぬと、その人のボットは全部倒れます**（指揮権を譲渡中なら倒れません。下の「指揮権の譲渡」）。倒れたボット（倒された場合も）はすぐ消え、指揮メニューの一覧からも外れます。蘇生はしません。また呼ぶときは、`/sb revive` か兵科選択で新しく出します（新しく出たボットは全快で、方針は「ついてこい・持ち場優先」）。
  持ち主が死ぬと指揮もリセットされ、方針は「ついてこい・持ち場優先」（出したときと同じ）に、指示する相手は「全員」に戻ります。
  ボットだけが倒されたときは、方針はそのままです。
- 抜けると消えます。チームを移ると消え、`/sb revive` で新しい陣営で出し直します。

## ボットの参戦（コマンドブロック）

ボットが参戦する（新しく出る）のは、`/sb revive` を実行したときと、兵科選択で呼んだときだけです（倒れたボットは消え、蘇生はしない）。ボタン付きのコマンドブロック（インパルス・レッドストーンが必要）に書いておきます。

| コマンドブロックの中身 | 押したとき |
|---|---|
| `sb revive @p` | ボタンを押した人（いちばん近い人）のボットを、持っている全部参戦させる（1 体もなければ 1 体出す） |
| `sb revive @p 3` | ボタンを押した人のボットを 3 体にそろえる（足りない分を新しく出す） |
| `sb revive @p 2 archer` | ボタンを押した人の弓兵を 2 体にそろえる（ほかの兵種には手を付けない。剣兵は `soldier`、槍兵は `spearman`） |
| `sb revive @p archer` | ボタンを押した人の弓兵を全部参戦させる（1 体もなければ 1 体出す） |
| `sb revive @a[team=Attack]` | 攻めのチーム全員のボットを参戦させる |
| `sb revive @a` | 全員のボットを参戦させる（試合の開始ボタンなど） |
| `sb revive all` | オンラインの全員のボット |

出る場所は、陣営のリスポーン地点（未設定なら持ち主の横）です。生きているボットには何もしません。
数は `@a 2` のようにどの対象にも付けられ、1 人あたりの数になります（上限を超える数は上限に切り詰めます）。
すでに数より多く持っている人のボットは、多い分を消したり参戦させたりはしません。

兵種（`soldier` / `spearman` / `archer`）を書くと、その兵種のボットだけを数えます（数と兵種はどちらを先に書いてもよい）。
兵種を書かないと兵種を問わずに数え、新しく出すのは `units.default`（既定は剣兵）です。
上限（`max-per-player`）は全兵種の合計なので、剣兵を 5 体持っている人に `sb revive @p 2 archer` を押しても弓兵は出ません
（コマンドブロックの出力に「上限に届いたので 2体は出せませんでした」と出ます）。
コマンドブロックの出力（最後の結果）に、参戦した体数（新しく出した・もともといた）が出ます。

## 兵科選択（プレイヤーが兵種を選んで呼ぶ）

呼べる回数が 1 以上になると、「兵科選択」（紙、ホットバーの 8 番目）を持ちます。回数を使い切っても消えません（0.19.0 から。指揮権の譲渡・取り戻しもこの紙から）。
右クリックすると兵科選択の画面（`/sbc units`）が開き、剣兵・槍兵・弓兵のどれかを押すと、その兵種のボットを 1 体呼べます。
呼べる回数は、前もってコマンドブロックで決めておきます（決めると、その場で兵科選択が配られる）。

| コマンドブロックの中身 | 押したとき |
|---|---|
| `sb picks @p 3` | ボタンを押した人が、兵科選択で 3 回呼べるようにする（残りの回数を 3 にする） |
| `sb picks @a[team=Attack] 2` | 攻めのチーム全員の残りの回数を 2 にする |
| `sb picks @p add 1` | ボタンを押した人の残りの回数を 1 増やす（`add -1` で減らす） |
| `sb picks @a 0` | 全員を呼べなくする |
| `sb picks @p` | 残りの回数を見る（変えない） |

- 兵種を押すと回数を 1 使い、その兵種のボットを 1 体新しく出します。
- 1 人あたりの上限（`max-per-player`、全兵種の合計）に届いていれば呼べません（回数は使わない）。倒れたボットは消えるので、数に入りません。
- 回数が変わると、その人に「兵科選択で兵を呼べる回数: N 回」と知らせます。画面の右には残りの回数とボットの数が出ます。
- 回数はサーバーを止めると消えます（試合ごとにコマンドブロックで決め直す想定）。**死ぬと 0 になります**（0.18.0 から。譲渡中の自分の分も 0 になる）。
  リスポーン後にまた呼ばせるなら、コマンドブロックの `/sb picks` で決め直してください。
- 兵科選択は SiegeBot が配ります（ItemJoin は使わない）。一度持った人は、回数が 0 でも、死んでもリスポーン・参加のときに持ち直します（サーバーを止めるまで）。
  死んで落とすことはなく、捨てることもできません。ホットバーの 8 番目がふさがっていれば、空いている所に入ります（持ち物が満杯なら、次のリスポーンか回数の変更のときに渡す）。
  配るのは回数・譲渡が変わったときとリスポーン・参加のときだけです（箱にしまった紙は配り直さない）。
- `/sb revive` とは別のしくみで、`/sb revive` は回数を使いません。

### 指揮権の譲渡

兵科選択の画面の右端の本（「指揮権を譲渡」）を押すと、同じチームのオンラインのプレイヤーの頭が並ぶ画面が開きます（18 人ずつ。前後のページは 3 段目の矢印）。
頭を押すと、自分の兵と、自分の残り回数（`picks`）を、その人に譲ります（別の人に付け替えることも、「自分に戻す」で取り戻すこともできます）。

- 譲られた人は、預かっている兵にも指示でき（指揮メニューの一覧に入り、持ち主の名前が付きます）、兵科選択でも預かっている回数を使って呼べます。
  使う順番は、自分の分、次に預かった順です。呼んだ兵は、回数を渡した持ち主の兵として数えられ、その人の上限（`max-per-player`）の枠に入ります。
  どちらの上限にも空きがなければ呼べません（回数は使いません）。画面の「残り N 回」には、自分の分と預かりの内訳が出ます。
- 譲った人の自分の分の回数は、`/sb picks <対象>` の表示では「3回（Bobに譲渡中）」のように、預かっている人には「2回（預かり: Alice 3回）」のように出ます。
  `/sb picks` で回数を変えると、譲った相手にも「（あなたが代わりに使えます）」と知らせます。
- 譲る・戻す・付け替えるときは、その人についていっていた兵だけを、新しい指揮者についていくように変えます（持ち場を守っている兵や、別の人についていく兵はそのまま）。
  呼び寄せのクールダウン（`orders.call-cooldown-seconds`）と、CombatLog の戦闘中の判定は、実際に操作する指揮官（預かっている人）に掛かります。
- **元の持ち主（A）が死んでも、渡した兵は倒れず、譲渡も続きます**（0.19.0 から）。B がそのまま指揮し、A についていっていた兵は B についていきます。
  A の使っていない `picks` は 0 になります（B も使えなくなる）。兵の持ち主は A のままなので、残った兵は A の上限（`max-per-player`）の枠を使い続けます
  （A がリスポーンしてすぐ呼び直しても、枠が空くまでは呼べない）。A はリスポーン後に「自分に戻す」で兵を取り戻せます。
  譲渡先が同じチームにいない・死んでいるときは、今までどおり兵は倒れ、譲渡は解除されます。
- **受け取った指揮官（B）が死ぬと、A から預かっていた兵は倒れ、倒れた体数だけ A の `picks` に足されます。**
  持ち場を守っていた兵も含め、B が指揮していた A の出ている兵はすべて倒れます。A の使っていない `picks` も同時に A に戻ります（A は死んでいないので 0 にはならない）。
  ただし、**A が一度死んだ後も生き残っていた兵の分は足しません**（A の死で 0 になった回数が、兵を通して戻らないように）。足すのは、A が最後に死んだ後に呼んだ兵の分だけです。
  死んだ B 自身の `picks` は 0 になり、B 自身の兵はそのまま倒れます。A も同じ瞬間に倒れていた場合は、加算も通知もありません。
  注意: 指揮官がわざと死ぬと、傷ついた預かり兵を新しい `picks` に変えられます。`/sb revive` で出した兵を預けて指揮官が倒れた場合も、倒れた数だけ `picks` が増えます。
- **受け取った指揮官が抜ける・別のチームになる・オフラインになると、預かっていた兵（生きたまま）と使っていない `picks` は元の持ち主に戻ります。**
  持ち主がチームを抜けた・退出したときは、譲渡は解除されます。
- 譲渡は 1 段だけです（A が B に譲り、B が C に譲っても、A の兵は C には渡りません）。譲渡先は同じチームのオンラインのプレイヤーに限ります。
- 譲渡の状態はサーバーを止めると消えます。

## 指揮メニュー

ItemJoin を入れると、参加時とリスポーン時に「指揮棒」が配られます（ホットバーの 9 番目）。
指揮棒を右クリックすると指揮メニューが開きます（ItemJoin なしでも `/sbc` で開けます）。

| 段 | ボタン | 押したとき |
|---|---|---|
| 1 段目 | 全員に指示 / 指揮している各ボットの絵（2 体以上いるとき） | 指示する相手を選ぶ。左クリックでそのボットだけ、シフト+左クリックで選んでいるボットに足す（もう一度で外す）。何体でも一度に選べる。「全員に指示」は全ページのボットが対象。画面は開いたまま。他の人から預かっている兵には「持ち主: ○○」と出る |
| 1 段目 | 指揮しているボットの絵（1 体のとき） | 兵種と今の方針を表示する（倒れたボットは一覧から消える。預かっている兵なら持ち主も出る） |
| 2 段目の左端・右端 | 前のページ / 次のページ | 9 体以上のとき、8 体ずつのページをめくる（ページ番号は出ない。最初のページには「前」、最後のページには「次」は出ない）。画面は開いたまま |
| 2 段目 | ついてこい | 自分についてこさせる。画面を閉じる |
| 2 段目 | 呼び寄せる | 自分の所へ瞬間移動させる。動き（追従・守る地点）は変えないので、「守れ」のままなら守る地点へ歩いて戻る。CombatLog で戦闘中（プレイヤーを殴った・殴られた後の `combat-time` 秒）のあいだも呼べない（`orders.call-blocked-in-combat: false` で無効）。画面を閉じる |
| 2 段目 | 視点の先を守れ | メニューを開いたときに見ていたブロックの所へ行って、そこを守らせる。画面を閉じる |
| 2 段目 | 退却 | 戦闘をやめさせ、持ち場（「ついてこい」なら自分）へ戻らせる。戻る途中は戦わず、盾も構えない。着くと元の動きと構えに戻る（下の「退却」）。画面を閉じる |
| 3 段目 | 構え: 積極的 / 持ち場優先 | 構えだけを変える（動きはそのまま）。画面は開いたまま |
| 3 段目 | 閉じる | 画面を閉じる |

今の動きと構えのボタンは光ります。指示を受けたボットは「了解。地点 (12, 64, -30) を守る・持ち場優先」のように復唱します。

- **横隊**: 同じ持ち場のボット（同じ人についていく・同じ地点を守る）は、重ならないように横隊に並びます。
  5 体までは 1 列、6 体以上は 1 列最大 5 体の複数列（前の列が多め。6〜10 体は 2 列、11 体以上は 3 列以上。2 列目以降はさらに後ろ）で、間隔は 1.6 ブロックです。
  「ついてこい」なら相手の後ろに、相手の向き（45 度ごと）に合わせて並びます。「視点の先を守れ」なら守る地点を前の列の真ん中にして、指示したときに見ていた向きを向いて並びます（向きが決まっていなければ敵のリスポーン地点の方）。1 体だけなら今までどおりです。
- **視点の先**: 床を見ていれば床の上、壁を見ていれば壁の手前の地面を守ります。48 ブロック（`orders.hold-max-distance`）より遠い所や空を見ていると守らせられません。
- **積極的**: 持ち場から 24 ブロックまでの敵を追いかけます。
- **持ち場優先**: 持ち場から 8 ブロックまでの敵とだけ戦います。ただし、8 ブロック以内まで近づいた敵には、どちらの構えでも応戦します。
- **退却**: 今の狙いを捨て、持ち場（守る地点、または「ついてこい」の相手）へ全力で戻ります。戻る途中は攻撃されても戦わず、盾も構えません。
  - 着いたら退却は終わり、元の動きと構えで普段どおり戦います（積極的なら、近くの敵をまた追いかけます）。
  - 20 秒（`orders.retreat-timeout-seconds`）たっても着かなければ退却をやめます（詰まったまま戦わなくなるのを防ぐ）。
  - 新しい指示（ついてこい・守れ・構え）を出す、持ち主が死ぬ、ボットが倒れる、のどれでも退却は終わります。

### /sbc（一般プレイヤー用）

権限 `siegebot.command`（既定で全員）。自分のボットにだけ効きます。

| コマンド | 内容 |
|---|---|
| `/sbc` または `/sbc menu` | 指揮メニューを開く |
| `/sbc units` | 兵科選択の画面を開く（ボットがまだいなくても開ける） |
| `/sbc follow` | 自分についてこさせる |
| `/sbc hold` | 視点の先を守らせる |
| `/sbc call` | 自分の所へ瞬間移動させる（`orders.call-cooldown-seconds` で続けて使えない秒数を決められる。既定 0 で制限なし） |
| `/sbc retreat` | 退却させる（戦闘をやめて持ち場・自分の所へ戻らせる） |
| `/sbc stance [push\|guard]` | 構えを変える（引数なしなら切り替え） |
| `/sbc target` | 指示する相手を切り替える（全員 → 1 体ずつ → 全員） |
| `/sbc status` | 自分のボットの方針を表示する |

## 管理用コマンド（/sb）

権限 `siegebot.admin`（既定で OP）。`/sb` は `/siegebot` の短縮です。

| コマンド | 内容 |
|---|---|
| `/sb spawnpoint <attack\|defend> [clear \| x y z]` | 陣営のリスポーン地点を今いる場所（または座標）にする。`clear` で消す |
| `/sb spawn <名前> <attack\|defend> [soldier\|spearman\|archer]` | 試験用（`test-bots.enabled: true` のときだけ）: 持ち主のいないボットを出す。出した地点を守り、data.yml に保存されて起動時にも出る。倒れたものは `/sb revive bots` で出し直す |
| `/sb revive <プレイヤー\|@p\|@a\|all> [数] [soldier\|spearman\|archer]` | ボットを参戦させる（コマンドブロック用。数は 1 人あたりの体数。上の表を参照） |
| `/sb picks <プレイヤー\|@p\|@a\|all> [数 \| add 数]` | 兵科選択で呼べる回数を決める・足す・見る（コマンドブロック用。上の「兵科選択」を参照） |
| `/sb remove <名前>` | ボットを消す |
| `/sb list` | ボットと方針・持ち主の一覧 |
| `/sb set <ボット\|*> follow <プレイヤー> [push\|guard]` | 方針を直接設定する（追従） |
| `/sb set <ボット\|*> hold [push\|guard]` | 方針を直接設定する（自分の視点の先を守る） |
| `/sb set <ボット\|*> stance <push\|guard>` | 構えだけを変える |
| `/sb set <ボット\|*> retreat` | 退却させる（コマンドブロックで「全軍退却」などに使える。`*` で全ボット） |
| `/sb tp <ボット> [x y z]` | ボットを瞬間移動させる（座標なしなら自分の所へ。詰まったときの救出用） |
| `/sb protect <ボット> <on\|off>` | ボットを無敵にする・戻す（試験用） |
| `/sb debug` | 各ボットの兵種・位置・体力・狙っている相手・方針・戦闘中の残り秒数・盾の状態・手に持っている物（`hand=iron_axe(model=1)` など。弓兵は弓の状態も） |
| `/sb map` | 適用中のマップ（`default` またはマップ名。`extends` の親も）を見る |
| `/sb map list` | `maps/` にあるマップの一覧（適用中のものに「（適用中）」） |
| `/sb map <マップ名>` | マップ別の設定に切り替える（data.yml に保存され、再起動しても続く）。すでに適用中なら何もしない |
| `/sb map default`（`reset`） | `config.yml` だけの設定に戻す |
| `/sb debug units [attack\|defend]` | 兵種ごとに今使っている値（速さ・火力・防御力・体力・届く距離・装備など）と、主な設定の値を出す。1 行目に適用中のマップ。攻め・守りで設定が違うときは両方、`attack` / `defend` を付けるとその陣営だけ |
| `/sb debug kb` | ボットのダメージとノックバック、弓兵の撃った矢、槍兵の突き（届いた距離つき）を 1 件ずつサーバーのログに出す（もう一度で止める。原因の調査用） |
| `/sb reload` | 設定（`config.yml`・`maps/`・data.yml）の読み直し。装備と盾の耐久は触らない |

## マップ別・陣営別の設定

マップごと・攻めと守りごとに設定を変えられます（0.17.0 から）。`config.yml` に変えたい項目だけを足す形で、書かなかった項目は `config.yml` のままです。

- **マップ別**: `plugins/SiegeBot/maps/<マップ名>.yml` に、そのマップで変えたい項目だけを書きます（`config.yml` と同じ書き方。`maps/` は起動時に作られ、中身は空です）。
  マップ名は半角の英数字・`_`・`-` の 1〜64 文字で、`default`・`reset`・`list` は使えません。大文字小文字は区別せずに探しますが、同名のファイルが複数あれば完全に一致するものを先にします。
  ファイルの一番上に `extends: 親のマップ名` と書くと、その親の設定を引き継ぎます（親の親もたどれて、親は 8 段まで。循環はエラー）。
- **攻め・守り別**: `sides.attack` / `sides.defend` の下に書いた項目は、その陣営のボット（と、その陣営のプレイヤーに関わる処理）だけに効きます。`config.yml` にも、マップのファイルにも書けます。
  相手の陣営の `teams`、`extends`、`sides` の入れ子、旧 0.6 形式の `equipment:`、廃止した `personal-bots.enabled` は、`sides` の中にもマップのファイルにも書けません（警告して無視します）。

```yaml
# plugins/SiegeBot/maps/castle_a.yml
extends: wide_field          # 省略できる
combat:
  speed: 1.2                 # 両陣営に効く
sides:
  defend:                    # 守りだけ
    units:
      soldier:
        equipment:
          helmet: DIAMOND_HELMET   # ほかの部位は今のまま
```

### 優先順位

`config.yml` → 親のマップ → 対象のマップ の順に重ね、**後のファイルが勝ちます**。同じファイルの中では、`sides.<陣営>` が共通の部分に勝ちます。
つまり、上から順に ① `config.yml` の共通 ② `config.yml` の `sides.<陣営>` ③ 親マップの共通 ④ 親マップの `sides.<陣営>` ⑤ 対象マップの共通 ⑥ 対象マップの `sides.<陣営>` です。
たとえば `config.yml` の `sides.attack` で `combat.speed: 1.0` と書いていても、マップのファイルの共通の部分に `combat.speed: 1.3` があれば、攻めも 1.3 になります（マップの `sides.attack` に書けば攻めだけ別にできます）。

### 兵種の値と combat の値

兵種に明示した値（`units.<兵種>.speed`・`damage-multiplier`・`defense-multiplier`・`attack-range`・`attack-delay-ticks`）は、`combat` の同じ名前の値より優先されます。
全兵種に `speed` などが書いてある `config.yml` では、マップの `combat.speed` を変えても効かないので、マップ側でも `units.<兵種>.speed` を変えてください。
槍兵の `attack-range` と `attack-delay-ticks` は `combat` を継がず、`units.spearman` の値（書かなければ 4.5 と 22）です。

### 装備は部位ごとに重なる

`units.<兵種>.equipment` は、直前までの設定の装備を元に、書いた部位だけを変えます（`config.yml` に装備が書いてなければ、兵種の組み込みの既定が元です）。
部位を外すときは `AIR`・`NONE`・`""`（空）のどれかを書きます（警告は出ません）。全部外すときは `equipment: {}` と書きます。`offhand` と `off_hand` は同じ部位です。

### 切り替えるときの注意

- 同じマップへの `/sb map` は何もしません（読み直しは `/sb reload`）。実際にマップが切り替わったときだけ、出ているボットの装備と盾の耐久が新しい設定で入れ直されます（盾の耐久は満タンに戻る）。
- `max-per-player` を下げても、すでにいるボットは消えません。次に出す・参戦させるときから上限が効きます。
- `teams` を変えるマップへ切り替えると、所属が合わなくなった専用のボットは消えます。試合の開始前に切り替えてください。
- マップの名前は data.yml の `map:` に保存されます。読めない（ファイルを消した・書き方の間違い）ときは、警告を出して `default` で動きます（data.yml の名前は残るので、直して `/sb reload` すれば戻ります）。
- 攻めと守りのチーム名が同じになるマップへは切り替えられません。

## 兵種

| 兵種 | 名前 | 戦い方 | 既定の装備 |
|---|---|---|---|
| 剣兵（`soldier`） | 「名前の兵」 | 敵に近づいて斬る。盾で矢を防ぐ | 鉄の剣・盾・鉄の防具 |
| 槍兵（`spearman`） | 「名前の槍兵」 | 届く距離が 4.5 ブロックと長く、届くぎりぎりの所から突く。殴り合いの最中も飛んでくる矢は盾で防ぐ | 槍（鉄の斧・`custom_model_data` の文字 `"1"`）・盾・鉄の防具（脚はチェーン） |
| 弓兵（`archer`） | 「名前の弓兵」 | 離れた所から矢を撃つ。盾は持たない | 弓・チェーンの兜・革の防具 |

指揮メニューでは、ボットの絵が兵種の武器（剣・斧・弓）になり、説明に兵種が出ます。指示（ついてこい・守れ・構え・退却）はどちらも同じです。

**エイム**（数値は `config.yml` の `units.<兵種>.aim`）: ボットは見えない照準を持ち、プレイヤーのように狙います。

- 照準は狙う相手の方へ、1 tick に `turn-speed` 度までしか回りません（0 で一瞬で向く）。相手がいなければ照準は体の向きに合わせるので、後ろから来た敵には振り向く時間がかかります。
- 照準は `sway` 度ほどの大きさでゆっくり揺れます（0 で揺れない）。
- 照準を大きく回すほど揺れが大きくなります。1 tick に 1 度回すごとに、その tick の揺れに `turn-sway` 度を足します（0 で回しても増えない）。揺れは数 tick で元の大きさに戻るので、大きく振り向いた直後の攻撃・矢ほど外れやすくなります。
- 反応の遅れ: `reaction-ticks`（既定 2 tick = 0.1 秒、0 で遅れなし。0〜20 tick の範囲で制限）だけ前の位置・向きを見て照準を回します（剣兵・槍兵は相手の胴の座標、弓兵は弾道の向き）。
  盾を構えている間は遅らせず（脅威の向きへすぐ向く）、履歴も消します。相手が変わったとき・狙いがなくなったときも履歴を消します。
- 剣兵・槍兵: 攻撃のたびに、揺れを含めた照準の線が相手の当たり判定に入っていれば当たり、外れていれば空振りします。
- 弓兵: 引き切っても、照準が弾道の向きから 1.5 度以内に来るまで撃ちません。矢は揺れを含めた照準の向きに飛びます（その上に `inaccuracy` のぶれも掛かる）。
  動く敵への先読みの割合は `lead-factor`（既定 0.7、1.0 で正確に先読み、0.0 で先読みしない、0.0〜1.5 で制限）です。
  弓兵は 2 tick ごとに弾道を更新するので、発射時の実効の遅れは 2〜4 tick になります。遅れによるずれが 20 度を超えている間や、狙う相手を切り替えた直後は、古い向きで撃たずに待ちます。
  間に味方がいるかは、実際に撃つ照準の向き（揺れ込み）と今の弾道の向きの両方で確かめます。

| 兵種 | `turn-speed`（度/tick） | `sway`（度） | `turn-sway`（度/回した度） | `reaction-ticks`（tick） | `lead-factor` |
|---|---|---|---|---|---|
| 剣兵 | 15 | 5.5 | 0.8（15 度振り向くと揺れ 17.5） | 2 | — |
| 槍兵 | 12 | 3.8 | 0.7（12 度で 12.2） | 2 | — |
| 弓兵 | 9 | 1.8 | 1.0（9 度で 10.8） | 2（実効 2〜4 tick） | 0.7 |

実機試験の結果（Paper 26.1.2 の検証サーバー。括弧内は Clopper–Pearson の 95% 信頼区間）:
- 剣兵: 静止した相手には 258/260 回命中（99.2%、97.2%–99.9%、遅れ 0.0°）。半径 1.9 ブロックを約 0.22 ブロック/tick で周回する相手には 338/656 回命中（51.5%、47.6%–55.4%、平均遅れ 17.0°）。
- 槍兵: 距離 4.0 ブロックの静止した相手には 1250/1376 回命中（90.8%、89.2%–92.3%、遅れ 0.0°）。半径 3.8 ブロックを約 0.23 ブロック/tick で周回する相手には 495/1426 回命中（34.7%、32.2%–37.2%、平均遅れ 10.3°）。
- 弓兵（距離 20 ブロック）: 静止した相手には 547/1008 本命中（54.3%、51.1%–57.4%）。半径 4.0 ブロックを約 0.22 ブロック/tick で周回する相手には 236/756 本命中（31.2%、27.9%–34.7%）。

強くしたければ `sway`・`turn-sway`・`reaction-ticks` を下げて `turn-speed` を上げ（弓兵は `lead-factor` も `1.0` に近づけ）、弱くしたければその逆にします。
`/sb debug` の `aim=` に、照準の狙いからのずれ・反応の遅れによるずれ・今の揺れ・直前に回した角度が出ます（`ずれ0.0°(遅れ0.0°,揺れ2.6°,回した0.4°)`）。`/sb debug kb` の間は、近接の攻撃ごとに当たり（`HIT`）・空振り（`MISS`）をログに出します。

**槍兵の動き**（数値は `config.yml` の `units.spearman`）:
- 槍は、本サーバーのリソースパックで槍の見た目になる鉄の斧（`minecraft:iron_axe[custom_model_data={strings:["1"]}]`）です。
  リソースパックのないサーバーでは、ただの鉄の斧に見えます。強さも鉄の斧のまま（1 撃 9。盾で防いでいる相手の盾を 5 秒使えなくする）です。
- 届く距離は 4.5 ブロック（`attack-range`。目から相手の当たり判定までの距離で、プレイヤーの剣は 3.0）。
- 敵へ近づくと、届く距離より 0.2 ブロック（`stop-inside`）内側の所で止まり、そこから突きます。試験では 4.15〜4.46 ブロックから突きました。
- 突く間隔は 22 tick（`attack-delay-ticks`。鉄の斧と同じ 1.1 秒。短くすると、プレイヤーと同じく力が溜まらず弱くなる）。
- 敵が 3.0 ブロック（届く距離 − `back-off-inside: 1.5`）より近くまで寄ってくると、届くぎりぎりまで下がって間合いを取り直します。下がる間は突きません。
  試験では、殴り返してくる剣兵と 1 対 1 で戦って勝ちました（寄られた直後に 2 発受けた）。
- 蜘蛛の巣: 敵を追う道に蜘蛛の巣があれば、その敵を追いません（構えに関係なく。`avoid-cobweb: true`）。
  2 秒後にもう一度見直します（巣が壊された・敵が動いたら追う）。届く距離の敵には、巣の向こうでもその場で突きます。
  `/sb debug` の `巣で追わない=` が、今追わないでいる敵の数です。試験では、巣の壁の向こうの敵を追わず、巣に一度も触れませんでした。
- 盾: 殴り合いの最中でも、飛んでくる矢（飛び道具）は盾で防ぎます（突くより優先）。防ぐ間は止まって矢の方を向き、突きません。
  殴り合いの最中は、弓を向けられているだけでは構えません（矢が飛んできたときだけ）。殴り合いでないときは剣兵と同じく、弓を向けられても構えます。
  脅威がなくなったらすぐ下ろして（`shield-lower-after-seconds: 0`）、また突きます。
  試験では、突いている最中に横から撃ち込んだ矢を 6 本とも防ぎ、毎回 0.2 秒以内に下ろして突き直しました。

**弓兵の動き**（数値は `config.yml` の `units.archer`）:
- 見えていて 32 ブロック（`range`）以内の敵には、止まって弓を引き、1 秒（`draw-ticks: 20`）で引き切って撃ちます。撃ってから 0.5 秒（`shot-interval-ticks: 10`）で次を引き始めます。
- 見えて `range` 以内の敵は、構え（積極的・持ち場優先）や持ち場からの距離に関係なく撃ちます（城壁の上から届く敵を撃つ）。試験では 20・30 ブロック先の敵に、どちらの構えでも 5 本中 5 本当たり、34 ブロック先は撃ちませんでした。
  見えない・遠い敵へは近づきますが、近づくのは剣兵と同じく持ち場から `guard-leash` / `push-leash` の内の敵だけです。
- 積極的のときは、敵が 5 ブロック（`min-distance`）より近いと、10 ブロック（`keep-distance`）まで下がります。下がる間は撃ちません。下がれる場所がなければ、その場で撃ちます。
  持ち場優先のときは下がらず（逃げず）、近くの敵もその場で撃ち続けます。
- 矢は重力で落ちるのを計算して山なりに撃ち、動いている敵は飛ぶ時間の分だけ先を狙います（上下の動きは見越しません）。既定では `aim.lead-factor: 0.7` で先読みを甘くしています。
  狙いには、プレイヤーの弓と同じくらいのぶれ（`inaccuracy: 1.0`）があります。
- 間に味方がいるときは、引いたまま撃たずに待ちます（すぐ隣の味方は気にしません）。試験でも、味方が射線上に立っている間は撃たずに待ちました。
- 矢は尽きず、拾えません。ダメージは引き切ったプレイヤーの弓の 1.5 倍（9、会心で最大 14。`arrow-damage: 3.0`、プレイヤーの弓は 2.0）で、`combat.damage-multiplier` も掛かります。
- 敵の剣兵は、弓兵が狙っているのに気づくと盾を構えます。正面から撃っても盾で防がれるので、横や後ろから撃つと当たります。

**兵種の設定**（`config.yml` の `units`）: 兵種ごとに、名前の後ろの文字（`name-suffix`）と装備（`equipment` の各部位: `hand`・`off_hand`・`helmet`・`chestplate`・`leggings`・`boots`）を変えられます。
速さ（`speed`）・火力（`damage-multiplier`）・防御力（`defense-multiplier`）・体力（`max-health`、20 でハート 10 個）も兵種ごとに書けます。
書かなければ `combat` の値（体力は 20）を使います。剣兵は `attack-range`・`attack-delay-ticks` も書けます（書かなければ `combat` の値）。
`/sb debug units` で、兵種ごとに今使っている値と装備を確かめられます。体力を変えたときは、次に出した・参戦したボットから満タンがその値になります（出ているボットは `/sb reload` で最大値だけ変わる）。
装備は、アイテムの ID（`IRON_SWORD`）か、`/give` と同じ部品つきの書き方（`'minecraft:iron_axe[custom_model_data={strings:["1"]}]'`、YAML では `'` で囲む）で書きます。
読めないアイテムは、起動時・`/sb reload` のときにサーバーのログに警告を出して飛ばします。
設定を変えて `/sb reload` しても、今出ているボットの装備は変わりません（次に新しく出したボットから）。`/sb map` でマップを切り替えたときだけ、出ているボットの装備も入れ直されます。

## 知っておくこと

- **ボットどうしが重ならない**（0.16 から）: 毎 tick、水平の距離が `separation.min-distance`（既定 0.9 ブロック。0.6〜1.5）より近いボットの組を押し分けます。
  人間のプレイヤーは対象外です。縦に 1.8 ブロック以上離れていれば重なりとは見ません。出す・呼び寄せる（`/sbc` の呼び寄せ）・`/sb tp` でも、先にいるボットと重ならない近くの立てる所に出ます
  （足場がなく探せないときだけ重なることがあります）。ダメージを受けた直後・登れるブロックや液体・蜘蛛の巣の中・乗り物の上・空中にいるボットは押しません（他のボットからは避けられます）。
  押す先が崖（2 ブロック以上の落ち）・液体・溶岩・火・マグマ・粉雪などなら、その向きには押しません。
  同じ陣営のボットが 1 マスの通路などで向かい合って逆向きに歩いているときだけは、プレイヤーどうしがぶつかったときと同じく弱い押しだけで、すれ違えます（敵どうし・同じ向き・敵を追っているときは通常どおり押し分けます）。
  横隊では、自分の位置に着いたあとは少し離れるまで歩き直しません（縁で行ったり来たりしない）。`separation.enabled: false` で全部やめられます。古い `config.yml`（`separation` の節がない）でも、既定値（有効・0.9）で動きます。
  `/sb debug` の最後の行 `間隔: 最小 0.93 / 重なり(<0.6) 0組` で、いまのボット全体の水平の最小距離と、重なっている組の数（0.6 ブロック未満）を見られます（組がなければ「間隔: 対象なし」）。
  各ボットの行の `sepDir=path / vel / none` は、歩いている最中の進む向きを何から決めたか（経路・速度・分からない）です。
- **歩ける距離**: 持ち場が `combat.path-range`（既定 96 ブロック）より遠いと、経路が見つからず歩けません。
- **飛び降り**: 高さを気にせず飛び降ります（`combat.max-fall-distance`、既定 384 ブロック = ワールドの高さ全部）。
  落下のダメージはプレイヤーと同じく受けるので、高すぎると落ちて倒れます。受けないようにするなら `combat.fall-damage: false` にしてください。
  飛び降りの経路は `combat.pathfinder: MINECRAFT`（0.4.1 からの既定）でしか見つかりません。CITIZENS 系にすると高い所で止まります。
- **詰まったとき**: 瞬間移動はさせていません。歩いているのに進まなくなったら、自動で復旧します（0.16 系から）。
  進んだかは、位置が 0.9 ブロック以上動いたか、目標までの距離が縮んだかで見ます。後退と横隊の直線寄せは 1 秒、ふつうの歩きと敵の追跡は 1.5 秒進まなければ、歩きを取り消して引き直します。
  後退は進んでいても 2 秒で打ち切り、1.5 秒は再び下がりません。横隊の直線寄せで詰まったときは、持ち場のそばならその場で待ち、離れていれば 3 秒だけふつうの経路探索で歩きます。
  同じ敵への追跡が 2 回続けて詰まったら、その敵を 2 秒（続くたびに 4 秒・8 秒）狙いから外して別の敵を探します（攻撃・射撃が届く位置の敵は外しません）。
  弓兵は、引き切ったあと味方が射線に 0.8 秒いると、その敵を 1.5 秒狙わず別の敵を探します。
  槍兵は、構えているだけで矢の飛んでいない弓には 1.5 秒しか足を止めず、そのあと 2 秒は未発射の弓では止まりません（飛んでくる矢は今までどおり止まって防ぎます）。
  `/sb debug` の各行に `path=空 / path=直線`・`backoff`・`shieldStop`・`stuck=〇t`・`unreach=〇`・`lineBlk=〇` が出て、最後に `復旧: empty=3 chase=1 ...`（復旧した回数。なければ「復旧: なし」。`/sb reload` で 0 に戻る）が出ます。
  それでも動けないときは `/sb tp` で救出してください。
- **追従の相手**: 持ち主が倒れている間や、敵の陣営に移ったときは、その場で近くの敵と戦います。
- **狙いの選び直し**: 一度狙った敵でも、2 秒ごと（`combat.retarget-seconds`）に周りを見直し、今の相手より 2 ブロック以上近い敵がいれば狙いを替えます。
- **敵**: 敵の陣営のプレイヤーとボットに加え、敵のチームに入っているモブ（`/team join Defence @e[type=zombie]` などで入れたもの）も敵として狙います。
  自分の陣営のチームのモブと、どちらのチームにも入っていないモブには手を出しません。防具立ては狙いません。
  なお、モブの側がボットを襲うかどうかは、そのモブ自身の動き（バニラの AI）のままです。
- **敵に気づく条件**: 16 ブロック（`combat.engage-radius`）以内で、見えている敵だけを狙います（5 ブロック以内なら見えていなくても気づきます。弓兵は見えていれば `units.archer.range` まで）。壁の向こうの敵とは戦いません。
- **速さ**: `combat.speed: 1.5` で毎秒約 5.6 ブロック（プレイヤーのダッシュくらい）です。1.95 にすると毎秒約 7.2 ブロック（ダッシュジャンプくらい）になります。
  これらは CITIZENS 方式で測った値で、MINECRAFT 方式（0.4.1 からの既定）では 1.5 で毎秒約 5.4 ブロックでした。
- **名前の表示**: ボットの頭の上の名前は、同じ陣営（チーム）のプレイヤーにだけ見えます（`name-tag.visible-to: team`）。
  敵やチームに入っていない人には見えません。`all` にすると全員に見えます。
  Citizens の名前の表示はプレイヤーごとに出し分けられないので、代わりにボットに文字の表示（テキストディスプレイ）を乗せています。
  文字の色は所属チームの色（`/team modify <チーム> color <色>`）と同じです。チームの色が未設定（`reset`）のときや、チームがないときは白になります。
  試合中にチームの色を変えても、最大 0.5 秒ほどで追従します。
  `team` でも `all` でも文字の表示を使うので、バニラのプレイヤー名と違って、壁の向こうからは見えません。
  プレイヤー自身の名前も同じようにするには、`/team modify Attack nametagVisibility hideForOtherTeams`（Defence も同じ）を実行します。
- **自動の回復**: 生きているボットは、2 秒ごと（`combat.regen-interval-seconds`）に体力が 1（ハート半分、`combat.regen-amount`）ずつ戻ります。
  空から満タン（20）まで約 40 秒です。ダメージ（攻撃・落下・炎など）を受けてから 10 秒（`combat.regen-delay-seconds`）は回復しません。
  `combat.regen-amount: 0` で回復しなくなります。
- **盾**: ボットは左手に盾を持ち、プレイヤーと同じように使います（`shield.enabled: false` で使わない）。
  - 盾はプレイヤーと同じく、防ぐたびに削れて、耐久がなくなると壊れます。壊れた盾は補充しません（そのボットは盾なしで戦い続ける。新しく出たボットは新品の盾を持つ）。
    `/sb debug` の `shield=` に残りの耐久が出ます。試験では、剣兵の盾（336）はダメージ 40 の矢 1 本で 41 削れ、9 本目で壊れました。
  - 耐久は兵種ごとに `units.<兵種>.shield-durability` で変えられます（0 で盾のアイテムのまま = 336）。槍兵の盾は既定で半分の 168 です。
    試験では、重い矢 1 本で 65 削れ、3 本目で壊れました（168 → 103 → 38 → 壊れる）。値を変えたときは、次に出したボットの盾から変わります。
  - 敵が弓・クロスボウ・トライデントで自分を狙っているとき（装填済みのクロスボウを向けているときも）と、矢が自分に飛んできているときに構え、そちらを向きます。
  - 狙っている敵が攻撃の届く距離 + 1 ブロック以内にいる（近接で殴っている最中）ときは構えません（槍兵は、飛んでくる矢だけは防ぐ）。
  - 脅威がなくなって 0.5 秒（`shield.lower-after-seconds`）で下ろします。構えている間は遅く歩きます（`shield.move-speed-multiplier`、既定 0.3 倍）。
  - 盾が防ぐのは、プレイヤーと同じく前から来た攻撃だけです。斧で盾を無効にされると、しばらく構えられません。
  - 盾で防いだときは、ノックバックで後ろに下がりません（防げなかった攻撃は今までどおり下がります）。
  - 構えた瞬間から防ぎます（`shield.blocking-delay-ticks: 0`）。プレイヤーの盾は構えてから 5 tick（0.25 秒）防げませんが、
    ボットは気づいてから構えるので、5 tick 待つと引き切った弓の速い矢に間に合いません。5 にするとプレイヤーと同じになります。
  - 盾を持つのは、兵種の装備の左手（`units.<兵種>.equipment.off_hand`）が盾のボットだけです（既定では剣兵と槍兵）。盾でなければ構えません。
- **強さ**: 火力 `combat.damage-multiplier`（既定 1.2）はボットが与えるダメージに掛け、防御力 `combat.defense-multiplier`（既定 1.2）はボットが受けるダメージを割ります。
  倍率は防具で減らす前のダメージに掛かるので、実際の差は倍率と少しずれます。鉄の剣と鉄の防具どうしで測った 1 撃のダメージ:

  | 火力 / 防御力 | 1 撃のダメージ |
  |---|---|
  | 1.0 / 1.0（倍率なし） | 約 3.1 |
  | 1.2 / 1.0（ボットがプレイヤーを殴るときに当たる） | 約 3.9 |
  | 1.0 / 1.2（プレイヤーがボットを殴るときに当たる） | 約 2.5 |
  | 1.2 / 1.2（ボットどうし） | 約 3.1（倍率なしと同じ） |
- **同士討ち**: ボットと、同じ陣営のプレイヤー・ボット・モブの間の攻撃は無効になります。
- **Citizens の初回起動**: Citizens は最初の起動のときに、必要なライブラリを外部（Maven Central）からダウンロードします。
- **まだできないこと**: クロスボウ・トライデント、ブロックの設置・破壊。

## 0.12 から上げるとき

jar を差し替えるだけで動きます（古い SiegeBot の jar は消してから入れる）。新しい項目（`separation`、`aim.reaction-ticks`、`aim.lead-factor` など）は、書かなければ既定の値で動きます。
`plugins/SiegeBot/maps/` のフォルダが自動でできます（中身は空のまま。マップ別の設定を使うときだけファイルを置く）。

- **エイムの既定が変わりました**（剣兵・槍兵・弓兵とも、振り向きが遅く揺れが大きい値に）。config.yml に `aim:` を書いている兵種は、書いた値のままです。新しい既定にするなら、その行を消すか、jar の config.yml の値に合わせてください。
- **兵科選択の回数は死ぬと 0 になります。** リスポーン後にまた呼ばせるなら、役職・リスポーンのコマンドブロックで `/sb picks @p <数>` を実行してください（`add` ではなく数を決める書き方なら、何度実行しても増えすぎない）。
- **兵科選択の紙は、回数を使い切っても消えません**（指揮権の譲渡もこの紙から）。
- 指揮権の譲渡（兵科選択の画面の本）が増えました。持ち主が死んでも、委任した兵は倒れません。

## 0.11 から上げるとき

持ち主のいないボット（`/sb spawn`・`/sb revive bots`）は試験用になり、`config.yml` に `test-bots.enabled: true` を書いたときだけ使えます（既定は false）。
false のままなら、data.yml に残っているボットは出ません（一覧は消さずに残す）。
`personal-bots.enabled` は廃止しました（ボットは常にプレイヤーの専用のボット）。config.yml の `personal-bots.enabled` の行は消してください（false と書いてあると起動時に警告）。

## 0.6 以前から上げるとき

すでにある `plugins/SiegeBot/config.yml` は書き換わりません。`units` の節がなければ、これまでの `equipment` の節を剣兵の装備として使い
（左手を書いていなければ、これまでどおり盾を持たせる）、弓兵は既定の装備・数値で出ます。
弓兵の装備や数値を変えたいときは、新しい `config.yml`（jar の中、またはリポジトリの `src/main/resources/config.yml`）の `units` の節を写してください。

## 0.4.0 以前から上げるとき

すでにある `plugins/SiegeBot/config.yml` は書き換わりません。高い所から飛び降りるようにするには、
`combat.pathfinder` を `"MINECRAFT"` に書き換えて `/sb reload` してください（`max-fall-distance`・`fall-damage` は書かなくても既定値が使われます）。

## 0.1 からの変更

0.2 で、前線・門の判定・場所の登録・チャットでの指示（キーワード判定と Claude API）をなくしました。
動きは「追従」と「視点の先を守る」の 2 つになり、jar に同梱していたライブラリもなくなりました。
0.1 の `data.yml` のリスポーン地点（場所の名前）は読めないので、`/sb spawnpoint` で設定し直してください。
0.1 の `config.yml` の `llm`・`chat`・`default-orders`・`gates` の項目は使われません（残っていても害はありません）。

## ビルド

Java 25 と Maven 3.9 以降が必要です。

```
mvn package
```

`target/SiegeBot-0.19.0.jar` ができます（単体テストも走ります）。
Windows では `build.cmd package` でも同じです（`tools/apache-maven-*` に Maven を置けばそれを、なければ PATH の `mvn` を使います）。
