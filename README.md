# SiegeBot — 攻城戦の兵士ボット

攻城戦で、プレイヤー 1 人に 1 体ずつ、その人の指示で動く兵士ボット（プレイヤーの姿の NPC）を付ける Paper プラグインです。
指揮棒を右クリックして開くメニューから、「ついてこい」か「視点の先を守れ」を選び、構え（積極的・持ち場優先）を決めます。

- 対応: Paper 26.1.2 / Java 25
- 必要なプラグイン: [Citizens](https://ci.citizensnpcs.co/job/Citizens2/)（2.0.44 build 4269 で確認）
- 任意のプラグイン: [ItemJoin](https://modrinth.com/plugin/itemjoin)（6.1.8 で確認。指揮棒を配るのに使う）、
  [CombatLog](https://modrinth.com/plugin/combatlogplugin)（1.2.1 で確認。入っていれば、戦闘中は「呼び寄せる」を使えない）
- 外部との通信: SiegeBot 自体はしません

## 導入

1. [Releases](../../releases) から `SiegeBot-0.4.2.jar` を取ってくるか、自分でビルドします（下の「ビルド」）。
2. サーバーの `plugins` フォルダに、Citizens の jar と `SiegeBot-0.4.2.jar` を入れて起動します。
   指揮棒を使うなら、ItemJoin の jar も入れ、[`itemjoin/items.yml`](itemjoin/items.yml) を `plugins/ItemJoin/items.yml` に置きます。
3. `plugins/SiegeBot/config.yml` の `teams.attack` / `teams.defend` を、攻め・守りのスコアボードのチーム名（`/team` で作ったチームの名前）に合わせ、`/sb reload` で読み直します。
   既定は `Attack` と `Defence` です。SiegeBot は大文字・小文字を区別せずに比べますが、コマンドのセレクタ（`@a[team=Attack]`）は区別するので、チーム名はそろえておくのが安全です。
4. 必要ならリスポーン地点を決めます（OP が必要）。その場所に立って実行します。
   ```
   /sb spawnpoint attack
   /sb spawnpoint defend
   ```
   決めない場合、ボットは持ち主の横に出ます。
5. ボットを出すコマンドブロックを置きます（下の「ボットの召喚と蘇生」）。

## 専用のボット

攻め・守りのチームに入っているプレイヤーに、その人専用のボット（「名前の兵」「名前2の兵」…）を出せます。
1 人が複数体持てます（上限は `personal-bots.max-per-player`、既定 5 体）。何体出すかはコマンドブロックで決めます。

- 参加しただけでは出ません。コマンドブロックの `/sb revive` で出します。
- 出た直後は、持ち主についていきます（持ち場優先）。
- 指示（指揮メニュー・`/sbc`）は、自分のボットにだけ効きます。他の人のボットには指示できません。
- ボットの発言（「了解。…」「到着した」「復活した」など）と死亡メッセージ（「○○の兵 was slain by …」）は、持ち主にだけ見えます。
  `/sb spawn` で出した持ち主のいないボットの発言と死亡メッセージは、同じ陣営の全員に見えます。死亡メッセージはサーバーのログにも残ります。
- **持ち主が死ぬと、その人のボットは全部倒れます。** 倒れたボット（倒された場合も）は自動では復活せず、`/sb revive` で蘇生するまで倒れたままです。蘇生すると全快で、方針はそのままです。
- 抜けると消えます。チームを移ると消え、`/sb revive` で新しい陣営で出し直します。
- `config.yml` の `personal-bots.enabled: false` にすると専用のボットは出ず、チームのボット全員にチームの誰でも指示できる形になります。

## ボットの召喚と蘇生（コマンドブロック）

ボットを出す・蘇生するのは、`/sb revive` を実行したときだけです。ボタン付きのコマンドブロック（インパルス・レッドストーンが必要）に書いておきます。

| コマンドブロックの中身 | 押したとき |
|---|---|
| `sb revive @p` | ボタンを押した人（いちばん近い人）のボットを、持っている全部蘇生する（1 体もなければ 1 体出す） |
| `sb revive @p 3` | ボタンを押した人のボットを 3 体にそろえる（倒れているものを蘇生し、足りなければ新しく出す） |
| `sb revive @a[team=Attack]` | 攻めのチーム全員のボットを出す・蘇生する |
| `sb revive @a` | 全員のボットを出す・蘇生する（試合の開始ボタンなど） |
| `sb revive bots` | `/sb spawn` で出した持ち主のいないボットのうち、倒れているものを蘇生する |
| `sb revive all` | 全員のボットと、持ち主のいないボット |

出る場所は、陣営のリスポーン地点（未設定なら持ち主の横）です。生きているボットには何もしません。
数は `@a 2` のようにどの対象にも付けられ、1 人あたりの数になります（上限を超える数は上限に切り詰めます）。
すでに数より多く持っている人のボットは、多い分を消したり蘇生したりはしません。
コマンドブロックの出力（最後の結果）に、出した・蘇生した体数が出ます。

## 指揮メニュー

ItemJoin を入れると、参加時とリスポーン時に「指揮棒」が配られます（ホットバーの 9 番目）。
指揮棒を右クリックすると指揮メニューが開きます（ItemJoin なしでも `/sbc` で開けます）。

| 段 | ボタン | 押したとき |
|---|---|---|
| 1 段目 | 全員に指示 / 自分の各ボットの頭（2 体以上いるとき） | 指示する相手を選ぶ（頭の説明に今の方針と生死）。画面は開いたまま |
| 1 段目 | 自分のボットの頭（1 体のとき） | 今の方針と、生きているか倒れているかを表示する |
| 2 段目 | ついてこい | 自分についてこさせる。画面を閉じる |
| 2 段目 | 呼び寄せる | 自分の所へ瞬間移動させる。動き（追従・守る地点）は変えないので、「守れ」のままなら守る地点へ歩いて戻る。倒れているボットは呼べない。CombatLog で戦闘中（プレイヤーを殴った・殴られた後の `combat-time` 秒）のあいだも呼べない（`orders.call-blocked-in-combat: false` で無効）。画面を閉じる |
| 2 段目 | 視点の先を守れ | メニューを開いたときに見ていたブロックの所へ行って、そこを守らせる。画面を閉じる |
| 3 段目 | 構え: 積極的 / 持ち場優先 | 構えだけを変える（動きはそのまま）。画面は開いたまま |
| 3 段目 | 閉じる | 画面を閉じる |

今の動きと構えのボタンは光ります。指示を受けたボットは「了解。地点 (12, 64, -30) を守る・持ち場優先」のように復唱します。

- **視点の先**: 床を見ていれば床の上、壁を見ていれば壁の手前の地面を守ります。48 ブロック（`orders.hold-max-distance`）より遠い所や空を見ていると守らせられません。
- **積極的**: 持ち場から 24 ブロックまでの敵を追いかけます。
- **持ち場優先**: 持ち場から 8 ブロックまでの敵とだけ戦います。ただし、8 ブロック以内まで近づいた敵には、どちらの構えでも応戦します。

### /sbc（一般プレイヤー用）

権限 `siegebot.command`（既定で全員）。自分のボットにだけ効きます。

| コマンド | 内容 |
|---|---|
| `/sbc` または `/sbc menu` | 指揮メニューを開く |
| `/sbc follow` | 自分についてこさせる |
| `/sbc hold` | 視点の先を守らせる |
| `/sbc call` | 自分の所へ瞬間移動させる（`orders.call-cooldown-seconds` で続けて使えない秒数を決められる。既定 0 で制限なし） |
| `/sbc stance [push\|guard]` | 構えを変える（引数なしなら切り替え） |
| `/sbc target` | 指示する相手を切り替える（全員 → 1 体ずつ → 全員） |
| `/sbc status` | 自分のボットの方針を表示する |

## 管理用コマンド（/sb）

権限 `siegebot.admin`（既定で OP）。`/sb` は `/siegebot` の短縮です。

| コマンド | 内容 |
|---|---|
| `/sb spawnpoint <attack\|defend> [clear \| x y z]` | 陣営のリスポーン地点を今いる場所（または座標）にする。`clear` で消す |
| `/sb revive <プレイヤー\|@p\|@a\|bots\|all> [数]` | ボットを出す・蘇生する（コマンドブロック用。数は 1 人あたりの体数。上の表を参照） |
| `/sb spawn <名前> <attack\|defend>` | 持ち主のいないボットを出す。出した地点を守る。保存され、再起動後も出る |
| `/sb remove <名前>` | ボットを消す |
| `/sb list` | ボットと方針・持ち主の一覧 |
| `/sb set <ボット\|*> follow <プレイヤー> [push\|guard]` | 方針を直接設定する（追従） |
| `/sb set <ボット\|*> hold [push\|guard]` | 方針を直接設定する（自分の視点の先を守る） |
| `/sb set <ボット\|*> stance <push\|guard>` | 構えだけを変える |
| `/sb tp <ボット> [x y z]` | ボットを瞬間移動させる（座標なしなら自分の所へ。詰まったときの救出用） |
| `/sb protect <ボット> <on\|off>` | ボットを無敵にする・戻す（試験用） |
| `/sb debug` | 各ボットの位置・体力・狙っている相手・方針 |
| `/sb reload` | 設定の読み直し |

## 知っておくこと

- **歩ける距離**: 持ち場が `combat.path-range`（既定 96 ブロック）より遠いと、経路が見つからず歩けません。
- **飛び降り**: 高さを気にせず飛び降ります（`combat.max-fall-distance`、既定 384 ブロック = ワールドの高さ全部）。
  落下のダメージはプレイヤーと同じく受けるので、高すぎると落ちて倒れます。受けないようにするなら `combat.fall-damage: false` にしてください。
  飛び降りの経路は `combat.pathfinder: MINECRAFT`（0.4.1 からの既定）でしか見つかりません。CITIZENS 系にすると高い所で止まります。
- **詰まったとき**: 瞬間移動はさせていません。経路があるのに 3 秒動かなければ、その場で経路を取り直します。動けないときは `/sb tp` で救出してください。
- **追従の相手**: 持ち主が倒れている間や、敵の陣営に移ったときは、その場で近くの敵と戦います。
- **狙いの選び直し**: 一度狙った敵でも、2 秒ごと（`combat.retarget-seconds`）に周りを見直し、今の相手より 2 ブロック以上近い敵がいれば狙いを替えます。
- **敵**: 敵の陣営のプレイヤーとボットに加え、敵のチームに入っているモブ（`/team join Defence @e[type=zombie]` などで入れたもの）も敵として狙います。
  自分の陣営のチームのモブと、どちらのチームにも入っていないモブには手を出しません。防具立ては狙いません。
  なお、モブの側がボットを襲うかどうかは、そのモブ自身の動き（バニラの AI）のままです。
- **敵に気づく条件**: 16 ブロック以内で、見えている敵だけを狙います（5 ブロック以内なら見えていなくても気づきます）。壁の向こうの敵とは戦いません。
- **速さ**: `combat.speed: 1.5` で毎秒約 5.6 ブロック（プレイヤーのダッシュくらい）です。1.95 にすると毎秒約 7.2 ブロック（ダッシュジャンプくらい）になります。
  これらは CITIZENS 方式で測った値で、MINECRAFT 方式（0.4.1 からの既定）では 1.5 で毎秒約 5.4 ブロックでした。
- **自動の回復**: 生きているボットは、2 秒ごと（`combat.regen-interval-seconds`）に体力が 1（ハート半分、`combat.regen-amount`）ずつ戻ります。
  空から満タン（20）まで約 40 秒です。戦闘中も回復します。`combat.regen-amount: 0` で回復しなくなります。
- **強さ**: 火力 `combat.damage-multiplier`（既定 1.2）はボットが与えるダメージに掛け、防御力 `combat.defense-multiplier`（既定 1.2）はボットが受けるダメージを割ります。
  倍率は防具で減らす前のダメージに掛かるので、実際の差は倍率と少しずれます。鉄の剣と鉄の防具どうしで測った 1 撃のダメージ:

  | 火力 / 防御力 | 1 撃のダメージ |
  |---|---|
  | 1.0 / 1.0（倍率なし） | 約 3.1 |
  | 1.2 / 1.0（ボットがプレイヤーを殴るときに当たる） | 約 3.9 |
  | 1.0 / 1.2（プレイヤーがボットを殴るときに当たる） | 約 2.5 |
  | 1.2 / 1.2（ボットどうし） | 約 3.1（倍率なしと同じ） |
- **体力**: ボットの体力は自然には回復しません。
- **同士討ち**: ボットと、同じ陣営のプレイヤー・ボット・モブの間の攻撃は無効になります。
- **Citizens の初回起動**: Citizens は最初の起動のときに、必要なライブラリを外部（Maven Central）からダウンロードします。
- **まだできないこと**: 弓などの遠距離攻撃、ブロックの設置・破壊。

## 0.4.0 以前から上げるとき

すでにある `plugins/SiegeBot/config.yml` は書き換わりません。高い所から飛び降りるようにするには、
`combat.pathfinder` を `"MINECRAFT"` に書き換えて `/sb reload` してください（`max-fall-distance`・`fall-damage` は書かなくても既定値が使われます）。

## 0.1 からの変更

0.2 で、前線・門の判定・場所の登録・チャットでの指示（キーワード判定と Claude API）をなくしました。
動きは「追従」と「視点の先を守る」の 2 つになり、jar に同梱していたライブラリもなくなりました。
0.1 の `data.yml` のリスポーン地点（場所の名前）は読めないので、`/sb spawnpoint` で設定し直してください。
0.1 の `config.yml` の `llm`・`chat`・`default-orders`・`gates` の項目は使われません（残っていても害はありません）。

## ビルド

Java 25 と Maven 3.9 以降が必要です。

```
mvn package
```

`target/SiegeBot-0.4.2.jar` ができます（単体テストも走ります）。
Windows では `build.cmd package` でも同じです（`tools/apache-maven-*` に Maven を置けばそれを、なければ PATH の `mvn` を使います）。
